# How-to-add-looping-in-.NET-MAUI-Rotator
This demo shows How to add looping in .NET MAUI Rotator (SfRotator)

This section explains how to enable looping in the .NET MAUI SfRotator control. Looping allows users to continuously navigate through rotator items without reaching a fixed beginning or end. When the last item is reached, the rotator automatically moves back to the first item, and when navigating backward from the first item, it seamlessly moves to the last item. This creates an infinite scrolling experience that improves navigation and user engagement.

The looping feature is particularly useful for image galleries, product showcases, promotional banners, onboarding screens, and media carousels where uninterrupted navigation is desired. Instead of stopping when the final item is displayed, users can continue swiping or navigating through the items in a circular manner, resulting in a smoother and more intuitive browsing experience.

The SfRotator control provides built-in support for looping, making it easy to create dynamic and interactive carousel interfaces. By enabling looping, applications can offer continuous content presentation while reducing the need for users to manually navigate back to the beginning of the collection. This behavior enhances usability and helps maintain user focus on the displayed content.

### Key Highlights

- Enables continuous navigation between rotator items.
- Automatically returns to the first item after the last item.
- Supports seamless backward navigation from the first item to the last item.
- Improves user experience with uninterrupted scrolling.
- Ideal for image galleries, banners, onboarding screens, and product showcases.
- Creates a smooth and engaging carousel experience.
- Easy to configure using the built-in SfRotator looping support.

By following the implementation steps, you can enable looping in the .NET MAUI SfRotator control and provide users with a seamless, circular navigation experience across all rotator items.
